让商家资料自动保持最新

商家认领通过后，可以生成一个自动同步令牌，然后让 Codex、Claude Code 或自己的定时任务更新中转导航上的资料。适合自动同步优惠活动、价格套餐、模型列表、用户规模和近期服务状态。

进入商家后台 查看接口规范
1. 登录商家后台

先完成商家认领并通过审核。登录后调用令牌接口生成自动同步令牌。

2. 交给自动化工具

把令牌放到商家的本地环境变量中，让工具读取官网信息后按标准 JSON 更新。

3. 前台自动展示

同步成功后，详情页会展示优惠、定价、模型和商家同步数据。

给 Codex / Claude Code 的提示词

你是某 AI API 服务商的运营资料维护助手。
请读取商家官网中公开展示的服务资料、优惠活动、模型覆盖、价格套餐和运营数据。
只同步能确认的信息，不确定的字段留空。
向 https://dhapi.pages.dev/api/merchant/sync/provider 发送 PATCH 请求。
请求头使用：Authorization: Bearer $DHAPI_MERCHANT_TOKEN
请求体按 /api/merchant/automation-spec 返回的 JSON 结构组织。

同步请求示例

curl -X PATCH "https://dhapi.pages.dev/api/merchant/sync/provider" \
  -H "Authorization: Bearer $DHAPI_MERCHANT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "profile": {
      "name": "Example API",
      "url": "https://example.com",
      "brands": ["OpenAI", "Claude", "Gemini"],
      "supported_models": ["gpt-4.1", "claude-3.5-sonnet"],
      "features": ["按量计费", "支持多模型"],
      "billing_type": "pay_as_you_go"
    },
    "promotion": {
      "enabled": true,
      "badge": "限时优惠",
      "title": "新用户充值加赠",
      "summary": "新用户首充可获得额外额度，活动以官网为准。",
      "code": "DHAPI20",
      "link": "https://example.com/promo"

    "metrics": {
      "user_count": 12000,

建议同步频率

优惠活动和价格建议每天同步一次；模型列表有变更时即时同步；用户数、请求量、近期状态等运营数据建议每 6-24 小时同步一次。这样用户在选择服务商时能看到更完整、更可信的信息。
